# time-series-causal-inference

Estudo de inferência causal e previsão em séries temporais financeiras usando o [Tigramite](https://github.com/jakobrunge/tigramite), de Jakob Runge (algoritmo PCMCI).

## Estrutura

| Caminho | Conteúdo |
|---|---|
| `notebooks/testes_iniciais.ipynb` | Primeiros testes com o Tigramite. |
| `notebooks/Causal_Inference_with_ML.ipynb` (e a cópia) | Inferência causal combinada com modelos de ML. |
| `notebooks/APRESENTAÇÃO  SLIDES  - Causal_Inference_with_ML.ipynb` | Versão em formato de apresentação. |
| `notebooks/Example.pdf` | Exemplo de saída. |
| `data/Doadores.xls` | Dados de exemplo. |

## Como rodar

```bash
pip install -r requirements.txt
jupyter notebook notebooks/
```
